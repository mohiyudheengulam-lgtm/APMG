# Module 3: Frontend UI

This folder is the workspace for Module 3, responsible for the web and chatbot interface used by procurement verification users.

## Responsibilities

- Provide document uploading and verification-request workflows.
- Present retrieved evidence, agent reasoning outcomes, compliance findings, and action status.
- Support clear user interaction with the local verification agent.
- Connect to the agentic engine through a documented, stable interface.

## Boundary

The frontend owns user experience and presentation. It does not implement document parsing, vector indexing, OKF conversion, or agent reasoning logic.
